跃传 LeapDrop 0.3.0
简单好用的 Mac / Windows 局域网文件互传工具

使用：
1. 两台电脑连接同一 Wi-Fi / 局域网，均打开跃传。
2. 选择对方设备，拖入文件，或点击选择文件。
3. 接收方确认保存，文件存入「下载/LeapDrop」文件夹。

无需账号，无需配对，无需填写 IP。文件不经过云端服务器。

接收控制：
设置 → 允许接收文件，默认开启并记住上次选择。
关闭后拒绝新的请求和待确认请求，仍然可以发送文件。
已确认开始的传输继续完成。开启接收时每次保存仍需确认。

首次启动：
Mac：打开 DMG 后将 LeapDrop 拖入「应用程序」。若提示无法验证开发者，
在「系统设置 → 隐私与安全性」选择「仍要打开」。允许本地网络权限。
Windows：解压后双击 leapdrop.exe。需要 Microsoft WebView2 运行时。
防火墙提示时允许「专用网络」。程序未使用商业代码签名证书。

扫描不到：
检查两台电脑是否在同一网段，防火墙是否允许，Wi-Fi 是否启用访客/AP 隔离。
多网卡或 VPN 可能影响发现和连接。

限制：
当前仅支持文件，文件夹请先压缩。不支持跨互联网传输、续传、暂停或取消。
传输中断后需重新发送。首次发现的设备没有身份认证，请在可信局域网使用。
两台电脑请使用 v0.3.0 或更新的兼容版本。
