# 跃传 LeapDrop v0.3.1

**新图标，依然简单好用。**

## 本版更新

- 全新青绿色双向折叠箭头图标，更新 Mac / Windows 应用图标、软件侧栏和项目首页。
- 项目采用 MIT License，许可全文随源码、Mac DMG 和 Windows ZIP 一同提供。
- 新增图标源文件与可复用的桌面图标生成脚本，便于后续维护。

## 使用方法

两台电脑连接同一 Wi-Fi / 局域网，同时打开跃传，选择对方设备并拖入文件，接收方确认保存即可。无需账号、无需配对、无需输入 IP。

「设置 → 允许接收文件」默认开启并记住上次选择；关闭后拒绝新的传输与待确认请求，仍可发送文件。已开始的传输继续完成。

## 下载

| 平台 | 文件 |
| --- | --- |
| macOS 11+，Apple Silicon / Intel 通用 | `LeapDrop_0.3.1_macOS_universal.dmg` |
| Windows 10 / 11，64 位 | `LeapDrop_0.3.1_Windows_x64.zip` |
| 下载校验 | `SHA256SUMS.txt` |

Mac 包采用 ad-hoc 签名，未做 Apple 公证；首次被拦截时，在「系统设置 → 隐私与安全性」选择「仍要打开」，并允许本地网络权限。Windows 包解压运行，需要 WebView2，未使用商业代码签名证书。首次防火墙提示时允许专用网络。

只支持同一局域网内传文件；文件夹请先压缩，不支持跨互联网、续传、暂停或取消。请在可信局域网使用，两台电脑均使用 v0.3.0 或更新的兼容版本。

Windows 包通过交叉编译构建，跨平台互传尚待 Windows 实机验收。许可详见 [MIT License](https://github.com/peng411528/leapdrop/blob/main/LICENSE)。
