# 跃传 LeapDrop v0.3.0

**简单好用，打开就能发现，拖入就能传。**

跃传是一款 Mac / Windows 局域网文件互传工具，适合办公室同事交换文档、家中台式机和笔记本传素材，以及 Mac 与 Windows 之间互传照片、视频和压缩包。

## 如何使用

1. 两台电脑连接同一 Wi-Fi / 局域网，同时打开跃传。
2. 在设备列表选中对方，拖入文件或点击选择文件。
3. 对方确认保存后开始传输，文件保存在「下载/LeapDrop」。

无需注册账号、无需配对、无需填写 IP 地址，文件无需经过网盘或第三方服务器。

## 本版功能

- 专注 macOS / Windows，移除移动端和跨网服务。
- 自动发现局域网内的设备，直接发起文件传输。
- 支持拖拽、多选、中文文件名、空文件和重名保护。
- HTTPS 加密传输、证书指纹核对、SHA-256 文件完整性校验。
- 显示发送与接收进度，每次保存前由接收方确认。
- 新增「允许接收文件」开关：默认开启，记住上次选择；关闭后拒绝新请求和待确认请求，仍然可以发送文件，已开始的传输继续完成。

## 下载哪一个

| 平台 | 文件 |
| --- | --- |
| macOS 11+，Apple Silicon / Intel 通用 | `LeapDrop_0.3.0_macOS_universal.dmg` |
| Windows 10 / 11，64 位 | `LeapDrop_0.3.0_Windows_x64.zip` |
| 下载文件校验 | `SHA256SUMS.txt` |

Mac：打开 DMG，将 LeapDrop 拖入「应用程序」。本版为 ad-hoc 签名，未做 Apple 公证；首次被拦截时，在「系统设置 → 隐私与安全性」选择「仍要打开」，并允许本地网络权限。

Windows：解压并双击 `leapdrop.exe`，无需安装。需要 Microsoft WebView2 运行时；未安装时可从 [微软官网下载](https://developer.microsoft.com/microsoft-edge/webview2/)。防火墙提示时允许「专用网络」。程序未使用商业代码签名证书，可能触发 SmartScreen。

## 使用范围与验证

当前只支持同一局域网内传文件。文件夹请先压缩；暂不支持跨互联网传输、续传、暂停或取消。传输中断后重新发送。首次发现的设备没有身份认证，请在可信的局域网内使用。

两端请使用 v0.3.0 或更新的兼容版本。旧版的配对流程已移除。

本版已通过 macOS 下的 8 项自动化测试，覆盖文件传输、接收拒绝、接收开关、偏好持久化及证书指纹不匹配等场景。Windows 安装包由交叉编译构建；Mac / Windows 双机互传仍需 Windows 实机验收。
